# README previews

The menu and hardware tester images are rendered from mono-retro's RG DS Plus
layouts at 1024×768 per screen, with a 16-pixel separator between the screens.
They are layout previews, rather than captures from a running handheld.

The menu uses representative battery data. The hardware tester uses its
`--preview` mode with `profiles/rg-ds-plus-rocknix.json`, so no controller or
touch device is connected. The launcher uses the [bundled Roboto font](../../assets/README.md).
